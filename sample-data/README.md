# Synthetic sample data

These records are invented for demonstration. They do not describe real people and must not be
combined with production or participant-level information.

- `valid-participants.csv` passes after safe formatting corrections.
- `invalid-participants.csv` demonstrates quarantine-worthy errors: missing and duplicate IDs,
  an unknown program code, an ambiguous boolean, an out-of-period date, and an invalid age group.
- `synthetic-staff-reports/` contains valid and invalid examples for five fictional staff-report
  profiles. See the [multi-program ingestion guide](../docs/synthetic-ingestion.md).
